## [0.1.0-beta.1](https://github.com/RasmusPJustesen/laravel-api-starter-kit/releases/tag/v0.1.0-beta.1) - 2026-11-25

- Laravel 13 API foundation, native JSON:API resources and both Sanctum modes.
- Password reset/confirmation, TOTP with recovery codes, device sessions and credential revocation.
- Multiple frontends, optional named collaboration module, personal entities, invitations, ownership transfers and lifecycle events.
- OpenAPI/Scalar/TypeScript contracts, stable errors and locale negotiation.
- Composer and Laravel installer integration, variant and database CI, HTTP contract validation and deployment documentation.

First public beta. Independent security review and installation from the public Packagist registry remain outstanding.
