# Contributing

Use a feature branch and submit focused pull requests. Include regression tests and documentation for behavioral changes. Run composer lint:check, composer types:check, composer test, composer audit and composer api:generate against a migrated local database. Test optional collaboration scaffolding in a clean disposable checkout; do not install it into the shared template and commit generated application files.

Keep dependencies minimal, use Laravel conventions, preserve Maestro attribution, and avoid application frontend dependencies. Report vulnerabilities privately as described in SECURITY.md.
