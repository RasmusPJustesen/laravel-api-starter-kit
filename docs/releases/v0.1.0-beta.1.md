## First public beta

A headless Laravel 13 API starter kit inspired by the Laravel Maestro API and teams proposals, without an application frontend.

### What's included

- Stateful Sanctum cookie authentication, stateless bearer tokens, or both.
- Registration, profile management, email verification, password reset and password confirmation.
- Optional or required TOTP two-factor authentication, QR setup and single-use recovery codes.
- Unified browser/native device management, revocable persistent sessions and bearer token rotation.
- Multiple frontend configurations, trusted origins and frontend-specific notification links.
- Optional collaboration module with custom singular/plural naming, personal entities, roles, permissions, invitations and ownership transfer.
- Scalar documentation, generated OpenAPI and TypeScript contracts, typed errors and locale negotiation.
- Laravel installer and Composer project integration, deployment guidance and automated tests.

### Try the beta

Requirements: PHP 8.3+, Composer 2, and Node.js 22+ for API type generation.

```bash
git clone --branch v0.1.0-beta.1 --single-branch https://github.com/RasmusPJustesen/laravel-api-starter-kit.git my-api
cd my-api
composer setup
php artisan serve
```

After Packagist registration and indexing, the explicit version can be installed with:

```bash
composer create-project rasmuspjustesen/laravel-api-starter-kit my-api 0.1.0-beta.1
```

### Validation and limitations

This release is published only after the complete GitHub Actions test matrix passes: PHP 8.3–8.5, SQLite/MySQL/PostgreSQL, base and custom-named team variants, both standalone authentication modes, HTTP contract checks, installation, Pint and Larastan. It is a beta, not an independently audited production-ready release. Packagist installation still needs verification after registry publication.
